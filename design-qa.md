## Comparison and fixes

1. Previous design used muted blue/sage surfaces and large sparse cards. Replaced its stylesheet with indigo gradients, emerald charts and answer states, white 18px cards, soft blue/lavender canvas, a local bold Arabic sans font and Phosphor icons.
2. Home now has centered branding, profile and bell controls, a native-language segmented picker, compact greeting, real progress ring, car/play CTA, two-by-two shortcuts and green daily goal. Mobile spacing was reduced after the first rendered review so the daily goal fits on the Kurdish 390×844 screen above the tab bar.
3. Lessons now have real working state filters and horizontal progress rows. A second screenshot review found rows too tall at 320px; repeated summary copy is now omitted on mobile (still present on lesson detail), making the rows compact like the reference. Practice search remains available in an expandable panel; questions have session progress and a purple explanation panel. Progress has real correct/incorrect/exam counts, mastery ring, topic strengths and weaknesses.
4. Navigation has the five requested tabs. All original routes remain reachable through the header menu and desktop sidebar. Desktop uses two columns and a four-item feature footer.
5. Fixed the overview link's accessible-name mismatch; updated layout tests for the new two-stat supplementary area without removing their equal-height assertions. Language tests now account for the persistent native-language selector and check switching in both directions.

## Required surfaces

- Typography: locally hosted Noto Sans Arabic with variable weights, German system sans; RTL/LTR and bilingual modes preserved. Heading, body, hint and counter hierarchy inspected.
- Spacing: phone screenshots at 320/390 and tablet/desktop layouts checked. Card rhythm, pill controls, nav and daily goal compared to reference. No device chrome duplicated.
- Colors: requested indigo/emerald palette implemented; semantic red/amber retained. Automated axe AA checks cover key routes and mobile states.
- Assets: official logo intact; no stretched/cropped logo. Icons and fonts bundled locally. Existing sign/media content retained rather than inventing traffic scenes.
- Copy/data: example 72%, 102 answers, 18 errors and 30 daily questions are not seeded into user data. Rings, totals and goals are computed from existing state. Production publication gates remain unchanged; lessons/questions awaiting expert review stay unavailable.

## Interaction coverage

Playwright checks primary navigation, language switching, lesson filtering/completion, answer feedback, search, exam scoring, persisted progress, offline use, accessibility, console errors, and narrow-screen overflow. Screenshots in test-results are generated by a real Chromium browser.

## Intentional differences and limits

- Reference example statistics are replaced with actual learner data, including zero-state rings.
- Existing bilingual mode remains the initial mode; Kurdish-only and German-only modes are immediately selectable.
- No new notification backend: the bell opens an honest learning reminder. Account/database/payment availability is unchanged.
- No decorative road photograph is inserted into a question that has no such media. Pending production content cannot be visually demonstrated as published without expert approval.
- Exact pixel matching to the perspective board is not measurable; this passes the usable responsive implementation of the supplied architecture and style, not an asserted 100/100 image similarity score.
